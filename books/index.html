How to add your own books (Layman's Guide)

You don't need coding knowledge or database setups to publish or archive books here.

  1. Add files: Place any .epub or .pdf book inside the folder books/archive/.
  2. Auto-index: Run npm run index:books (or node scripts/index_books.js) in your workspace terminal.
  3. Instant reader: That's it! Your book automatically receives a card on this shelf, full-text reading controls, and chapter navigation.
